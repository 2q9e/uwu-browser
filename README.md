# UwU Browser

UwU Browser is an independent Chromium-based browser project with its own product branding and a soft pink visual direction. This repository contains the Chromium source checkout under [`src/`](src). The current tree identifies itself as Chromium version 156.0.8073.0 in its version file.

## Where to start

- [Chromium source overview](src/README.md) explains how the upstream project is organized.
- [UwU product branding](src/chrome/app/theme/chromium/BRANDING) defines the application and installer names.
- [Chromium checkout instructions](src/docs/get_the_code.md) describe the platform-specific dependency and tooling setup. Use the build instructions for your operating system from the [Chromium documentation index](src/docs/README.md).
- [Chromium license](src/LICENSE) contains the upstream license and attribution. Component notices live alongside the relevant source.

The checkout alone is a source snapshot. Building it requires Chromium’s platform-specific dependencies and build tools.
